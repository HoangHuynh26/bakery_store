## Project Name
Bakery Store Landing Page

## Purpose

Build a simple, modern, responsive landing page for a bakery store for vietnameses people.

The page is a frontend-only project.

The main goal is to introduce the bakery, show its products and information,
and encourage visitors to contact the bakery or take the primary CTA.

## Scope

This project only focuses on frontend development.

The landing page should contain:

- Logo
- Navbar
- Hero/Header section
- Introduction
- Bakery information
- Featured products
- CTA sections
- Responsive layout
- Lazy loading for non-critical images
- Scroll-based navigation
- Final farewell/contact section
- About Me section
- Email/contact information

## Out of Scope

Do NOT implement:

- Backend
- Database
- Authentication
- Payment
- Admin dashboard
- API
- User accounts
- Complex business logic
- Access other file which is not relate to

## Main Goal

Create a complete single-page landing page from the top of the page
to the final farewell/contact section.

The user should be able to navigate through the entire page naturally
by scrolling.
