# Design Principles

## Design Direction

Create a modern, elegant, warm bakery landing page.

The design should feel:

- Warm
- Friendly
- Premium
- Clean
- Simple
- Professional

## Layout

Use a clear vertical page structure:

Navbar
↓
Hero
↓
About
↓
Featured Products
↓
Why Choose Us
↓
CTA
↓
Contact
↓
Farewell
↓
Footer

## Visual Hierarchy

The most important information should be:

1. Bakery name
2. Main value proposition
3. Primary CTA
4. Products
5. Contact information

## Typography

Use a clear and readable font.

Headings should be visually distinctive.

Body text should remain easy to read on mobile.

## Images

Use high-quality bakery-related images.

Images should:

- Have appropriate aspect ratios
- Not distort
- Use object-fit when necessary
- Use lazy loading below the fold

## Buttons

CTA buttons should be clearly distinguishable.

Buttons must have:

- Hover state
- Focus state
- Disabled state when appropriatez

## Responsive Design

Desktop:

- Full navigation
- Multi-column sections

Tablet:

- Reduced spacing
- Flexible grid

Mobile:

- Compact navigation
- Single-column content
- Large readable CTA buttons
- Touch-friendly controls

## Animation

Use subtle animations only.

Examples:

- Fade-in
- Slide-up
- Hover effects
- Smooth scrolling

Do not use excessive animations.

## Important Principle

The design should prioritize clarity and usability over visual effects.
